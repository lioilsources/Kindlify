# Kindlify — CLAUDE.md

## Overview

Flutter non-linear reader for ancient texts from the WorldLibraryProject corpus. Supports cross-references, non-linear navigation, and multiple ancient text formats.

## Commands

```bash
flutter pub get
flutter run -d ios
flutter run -d android
flutter run -d macos
flutter build ios
flutter build apk
flutter analyze
```

## Data Source

Texts come from the WorldLibraryProject corpus (`/Volumes/YOTTA/Dev/WorldLibraryProject` on M2, checked out next to this repo). The app imports **bundles** (`assets/bundles/*.json`: manifest tree + word cloud + summaries per node), parsed by `BookBundle.fromJson` in `lib/core/models/bundle.dart`.

- Bundles are generated by `rag/export_bundle.py` in WorldLibraryProject from its Postgres (`make bundles` in `rag/`); the format contract is enforced there by `validate_bundle()` — change both sides together.
- How to export, what to check and when a work is good enough to ship: `PLAN-kindlify-bundles.md` in WorldLibraryProject.
- The library list comes from `assets/bundles/index.json`. `rag/kindlify_sync.py` (WorldLibraryProject) exports every work the librarian has finished enriching, rewrites only bundles whose `pipelineVersion` changed, and regenerates the index — so the library grows without Dart changes. `pubspec.yaml` ships the whole `assets/bundles/` directory.
- `dao_de_jing.json` and `analects.json` are hand-written demos (`pipelineVersion: demo-*`) that the integration test relies on; exported bundles are named after the corpus id (`zh_daodejing.json`) and never overwrite them.

## Key Feature

Non-linear navigation: readers can jump between cross-references, annotations, and parallel passages rather than reading linearly.
